# ShadowFall AI - Платформа для автоматизации бизнеса

Это веб-приложение, созданное на стеке MERN (MongoDB, Express, React, Node.js). Проект включает в себя публичный лендинг, страницы с информацией об услугах, а также полнофункциональный личный кабинет пользователя с аутентификацией и защищенными роутами.

---

## 🚀 Основные возможности

- **Многостраничная структура:** Лендинг, Цены, Преимущества, FAQ.
- **Аутентификация пользователей:**
  - Регистрация с подтверждением по 6-значному коду на email.
  - Безопасный вход с использованием JWT (JSON Web Tokens).
  - Хеширование паролей для безопасного хранения.
- **Защищенные роуты:** Доступ к личному кабинету (`/dashboard`) только для авторизованных пользователей.
- **Личный кабинет (Dashboard):**
  - Несколько страниц: Главная, Мой Пакет, Marketplace, Профиль, Поддержка и т.д.
  - Динамическое отображение контента в зависимости от подписки пользователя.
- **Глобальное управление состоянием:** Использование React Context API для хранения информации о пользователе и его подписке.
- **Полный бэкенд:** Сервер на Node.js/Express для обработки всей бизнес-логики.
- **Интеграция с базой данных:** MongoDB Atlas для хранения данных о пользователях и их подписках.

---

## 🛠️ Стек технологий

### Фронтенд
- **React:** Библиотека для создания пользовательских интерфейсов.
- **React Router (`react-router-dom`):** Для навигации и создания многостраничного приложения.
- **Axios:** Для выполнения HTTP-запросов к бэкенду.
- **CSS Modules:** Для написания инкапсулированных стилей для компонентов.
- **React Icons:** Для использования иконок.

### Бэкенд
- **Node.js:** Среда выполнения JavaScript на сервере.
- **Express.js:** Фреймворк для создания веб-сервера и API.
- **MongoDB:** NoSQL база данных для хранения данных.
- **Mongoose:** ODM для удобной работы с MongoDB.
- **JSON Web Token (`jsonwebtoken`):** Для создания токенов аутентификации.
- **Bcrypt.js:** Для безопасного хеширования паролей.
- **Nodemailer:** Для отправки писем (коды верификации).
- **Dotenv:** Для управления переменными окружения.

## ⚙️ Установка и запуск

### Пререквизиты
1.  **Node.js** (версия 16 или выше).
2.  **npm** (обычно устанавливается с Node.js).
3.  Аккаунт на **MongoDB Atlas** для получения строки подключения к базе данных.

### 1. Настройка Бэкенда

1.  **Перейдите в папку `server`:**
    ```bash
    cd server
    ```
2.  **Установите зависимости:**
    ```bash
    npm install
    ```
3.  **Создайте файл `.env`** в папке `server` и заполните его по примеру ниже. **Эти данные нельзя загружать на GitHub!**
    ```env
    # Порт, на котором будет работать сервер
    PORT=5252

    # Строка подключения к вашей базе MongoDB Atlas
    MONGO_URI=mongodb+srv://...

    # Секретный ключ для JWT
    JWT_SECRET=your_super_secret_key_12345

    # Данные для отправки email (используйте пароль приложения Gmail)
    EMAIL_USER=your_test_email@gmail.com
    EMAIL_PASS=your_16_digit_app_password
    ```
4.  **Запустите сервер:**
    ```bash
    node server.js
    ```
    Сервер должен запуститься на порту 5252 и успешно подключиться к MongoDB.

### 2. Настройка Фронтенда

1.  **Откройте новый терминал** и перейдите в **корневую папку** проекта.
2.  **Установите зависимости:**
    ```bash
    npm install
    ```
3.  **Создайте файл `.env`** в **корневой папке** проекта (на одном уровне с `src`). Он нужен, чтобы React знал, куда отправлять запросы.
    ```env
    REACT_APP_API_URL=http://localhost:5252
    ```
4.  **Запустите React-приложение:**
    ```bash
    npm start
    ```
    Приложение откроется в браузере по адресу `http://localhost:3000`.
